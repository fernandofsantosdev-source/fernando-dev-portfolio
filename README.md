# Portfólio — Fernando Santos

Portfólio pessoal feito com HTML, CSS e JavaScript, com apresentação, habilidades,
projetos em destaque e links para contato.

## Como visualizar

Abra `index.html` em um navegador. O projeto não precisa de instalação, servidor
ou etapa de compilação.

## Personalização

- Edite os textos, habilidades e projetos em `index.html`.
- Ajuste cores e layout em `styles.css`.
- As interações e o conteúdo do currículo em texto ficam em `script.js`.
- O certificado de Git e GitHub fica em `certificados/git-e-github.pdf` e pode ser
  aberto pelo cartão da habilidade correspondente.
